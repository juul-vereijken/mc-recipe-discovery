# Recipe Discovery - README

## Installation
1. Drop recipe_discovery_v1.zip into your world datapacks/ folder
2. Run /reload or restart
3. doLimitedCrafting enables automatically

## Dungeons and Taverns Compatibility

If Dungeons and Taverns (DnT) is installed, Knowledge Books also appear
in 21 DnT structures. IMPORTANT: load Recipe Discovery AFTER DnT in the
datapacks screen (drag it to the bottom of the list). Otherwise DnT will
override our files and the books won t appear.

If DnT is NOT installed, the nova_structures loot table files are simply
never referenced by any chest in the world - completely harmless.

DnT structures supported:
  Overworld: Tavern, Firewatch Tower, Conduit Ruins, Mangrove Witch Hut,
             Ruin Town, Underground House, Badlands Miner Outpost,
             Illager Hideout (+ vegitarian variant), Illager Camp,
             Lost Bunker, Desert Ruins, Jungle Ruins, Swamp Village,
             Lone Citadel
  Nether:    Nether Keep, Stray Fort, Creeping Crypt,
             Nether Skeleton Camp, Piglin Outstation
  The End:   End Castle

## Note on DnT loot
Our files include approximations of DnTs original loot pools so players
still get both the normal drops AND the Knowledge Book. If DnT updates
its loot significantly, open an issue on GitHub and we will sync it.
